API Endpoints

This project provides several API endpoints to generate dynamic SVG cards:

  • /api/ - GitHub stats card
  • /api/top-langs - Top languages card
  • /api/pin - Repository pin card
  • /api/wakatime - WakaTime stats card
  • /api/gist - Gist card
